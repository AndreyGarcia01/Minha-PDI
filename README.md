# Minha-PDI

Objetivo do semestre
Um parágrafo explicando:

Sua motivação na disciplina
O que deseja dominar até o final
Como isso se conecta com seu futuro acadêmico ou profissional

Diagnóstico inicial
Autoavaliação honesta sobre:

Análise de complexidade
Divisão e conquista
Recursão
Programação dinâmica
Estruturas de dados
Grafos

Para cada tópico, descrever:

O que você já sabe fazer
O que ainda gera dificuldade
Metas técnicas (mínimo 3, máximo 5)

Para cada meta, incluir:
Contexto: por que é importante
Descrição: o que exatamente quer desenvolver
Plano de ação: ações concretas
Medição: como vai comprovar evolução
Prazo: até quando pretende atingir

Rotina semanal de estudo
Definir de 2 a 4 blocos fixos por semana, indicando:
Dia e horário
Tipo de atividade (teoria, exercícios, implementação, revisão)

Plano de uso de IA
Descrever:

Como pretende usar IA para aprender
Em quais momentos será apoio
Quais limites vai impor para evitar uso automático ou superficial
